# PDFs dos entregáveis

Coloque aqui os PDFs com **exatamente** o nome indicado no campo `file` do `catalog.js`
(ex.: `colecao-03-jardim-plantas-varanda.pdf`). Enquanto um arquivo não existir, o app mostra
um PDF provisório no lugar, e o painel lista quais ainda faltam.

Os PDFs não vão para o Git (estão no `.gitignore`). Em produção, envie para o volume
(`/data/content` no Docker).
